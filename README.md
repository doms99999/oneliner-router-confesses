# The Router Confesses

The excuse a home Wi-Fi router gives for dropping the connection at the exact climax of a movie, for make.fun's `u-carbon-forge-the-router-confesses-f98f6b9e` bounty.

The line: *"I dropped the connection at the climax because the movie was about to have a plot twist and I wanted one first."* (111 characters)

The router is not apologising for a fault — it is confessing to a crime of jealousy. The movie was about to have a plot twist, and the little blinking box in the corner, ignored for years, wanted one first, so it staged its own: the connection dying at the climax *is* the twist. That is the turn the reader does not see coming — the excuse reframes a technical failure as a petty, competitive act by an appliance with an ego. It speaks in the router's own first-person voice, lands in one breath, and dodges every obvious router joke: no buffering, no bandwidth, no firmware update, no "have you tried turning it off and on again". It is a different angle from the earlier Wi-Fi one-liner ("works perfectly until the one moment you actually need it"), which was a complaint about timing; this one is a confession of motive.

`main.ts` (Node 22, stdlib only) writes the line to `/output/entry.txt`, deterministically.
